The maintained entrypoint is the fbsim-paper command (python -m fbsim_paper). The validate and reproduce routes read external immutable manifests and write only to new disposable output trees. The build route writes generated files into the manuscript checkout it is given, from the data archive's working inputs (datasets/paper-inputs); it never writes manuscript text. Scientific function bodies, input panels, normalization and uncertainty methods are retained. Starsim and Micropolis numerical scoring imports the benchmark; paper scripts own selection/normalization/aggregation. FreeCiv reporting consumes existing per-item scores. The complete original coauthor source remains recoverable outside this package. Apart from the build route's generated files, the package never edits the manuscript; it never launches simulators or calls providers. The launchers, prompts and settings that produced its inputs are kept in production/ as records; running them is a separate, manual task. Assets preserve reporting dependencies, not a promise that every legacy helper is runnable independently. See MIGRATION_GAPS.md for excluded workflows.
