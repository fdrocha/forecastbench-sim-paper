The maintained entrypoint is the fbsim-paper command (python -m fbsim_paper). All routes read external immutable manifests and write only to new disposable output trees. Scientific function bodies, input panels, normalization and uncertainty methods are retained. Starsim and Micropolis numerical scoring imports the benchmark; paper scripts own selection/normalization/aggregation. FreeCiv reporting consumes existing per-item scores. The complete original coauthor source remains recoverable outside this package. The package never edits the manuscript, launches simulators or calls providers. The launchers, prompts and settings that produced its inputs are kept in production/ as records; running them is a separate, manual task. Assets preserve reporting dependencies, not a promise that every legacy helper is runnable independently. See MIGRATION_GAPS.md for excluded workflows.
